# John Marques — Portfólio

Este projeto nasceu da vontade de apresentar meu trabalho de um jeito que também tivesse a minha cara. Aqui reúno um pouco da minha trajetória como desenvolvedor full-stack, projetos que fizeram parte dela e as tecnologias com que gosto de construir produtos.

O visual segue uma ideia que fui lapidando ao longo do projeto: uma interface escura, direta e silenciosa, com o verde como ponto de atenção. A malha animada do hero foi feita para sugerir profundidade e movimento sem tirar o foco do conteúdo. O site também está disponível em português e inglês.

## O que você encontra por aqui

- Projetos pessoais e estudos técnicos
- Minha experiência profissional e áreas de atuação
- Versões em português e inglês
- Uma malha interativa em Three.js e pequenos detalhes animados com Motion

## Como construí

Usei Nuxt e Vue com TypeScript. A malha 3D é renderizada com Three.js; as animações de interface usam Motion. Mantive o conteúdo separado em `data/portfolio.ts` para facilitar as revisões em ambos os idiomas.

## Rodar localmente

```bash
npm install
npm run dev
```

Este é um projeto pessoal em evolução. As escolhas, experimentos e ajustes que aparecem aqui fazem parte do meu processo de construir uma presença profissional própria na web.
